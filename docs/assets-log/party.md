## 取り込み

シートの「歩行アニメーション（右向き）」の行（y=738〜815）を、キャラごとの範囲で切り出して変換した。

| キャラ | 切り出し範囲 |
|---|---|
| hero | `--crop 85,738,295,815` |
| swordsman | `--crop 320,738,545,815` |
| mage | `--crop 570,738,795,815` |
| priest | `--crop 810,738,1030,815` |
| thief | `--crop 1045,738,1270,815` |
| knight | `--crop 1290,738,1525,815` |

```bash
python3 -I tools/sprite-pipeline/build_sprites.py art/source/party_sheet_v1.png \
  --crop <範囲> --names <id> --walk-frames --scale-mode fit --body 42 --min-area 60 --out art/sprites/<id>
```

- 元画像の歩行ポーズは1体あたり縦約57px と小さく、ドットの格子を検出できないため `fit`（縦42ドット）で取り込んだ。スーパースター（縦41ドット）と大きさをそろえている。
- 出力: `art/sprites/<id>/<id>_right_0..3.png`（48×48、輪郭色を含め16色）

## 既知の問題

- **騎士**: 元画像の歩行4ポーズのうち、盾が描かれているのは4コマ目だけ。歩くと盾が出たり消えたりする。騎士の歩行4ポーズだけ再生成するのが望ましい。
- 全体に元画像のにじみが残り、スーパースターより少し色がくすんでいる（特に勇者のチュニック）。
- 既存キャラクターとの類似確認: 未実施（App Store 公開前に実施）。
- 正面・左向き・背面のポーズはシートにあるが、現時点では使っていない（次期で利用を検討）。

## v0.7 の変更（歩行アニメーション廃止）

- アプリで使う素材は**立ち姿の静止画1枚** `art/sprites/{id}.png` に変更した。元の歩行4コマは `art/archive/walk-v1/{id}/` に保管（アプリでは使わない）。
- 静止画は歩行4コマの1コマ目をそのまま使用。ただし騎士だけは、盾が描かれている4コマ目を使用（1〜3コマ目は盾が欠けていたため）。
