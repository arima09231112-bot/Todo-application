# Phase 2 の確認手順（RPGシステム）

コードを書いた環境には Swift がないため、**ビルドもテストも Mac で初めて実行します**。エラーが出たら、その文字を貼ってください。

## 1. 取り込みとテスト

リポジトリの一番上のフォルダで:

```bash
git pull
xcodegen
cd Packages/RPGTodoCore && swift test
```

抽選（重複なし・重み・再現性）と、加入演出の節目の判定のテストが通ることを確認します。

## 2. 実機で確認する

Xcode でスキーム `RPGTodo`・自分の iPhone を選んで ▶。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | アプリを開く | 画面の下に勇者（戦士）が1人だけ立っている |
| 2 | タスクを5件作り、1件完了（20%） | 仲間が1人、上から弾んで現れる |
| 3 | もう1件完了（40%） | 2人目が現れる |
| 4 | 1件のチェックを外す（20%） | 2人目が静かに消える（演出なし） |
| 5 | もう一度チェックを付ける（40%） | 2人目がすぐ現れる。**弾む演出は出ない**（1日1回） |
| 6 | 全部完了（100%） | 5人目が現れ、「全員集合！」が数秒出て消える |
| 7 | 1件だけのタスクを作って完了（100%） | 5人が順番に（約0.5秒間隔で）加わる |
| 8 | アプリを終了して開き直す | 顔ぶれと並び順が同じ |
| 9 | 設定タブ → 勇者の見た目を「戦士（女）」に変更 | ホームの勇者が女に変わる。ホーム画面のウィジェットも変わる（更新に少し時間がかかることがある） |
| 10 | 並んだ仲間の絵 | 勇者（戦士）と同じキャラは並ばない。同じキャラが2人いない |

## 3. 日付が変わるときの確認

1. 数件タスクを作って、何人か仲間を加える（顔ぶれを覚えておく）
2. iPhone の「設定」→「一般」→「日付と時刻」で、自動設定をオフにして日付を翌日にする
3. アプリを開く: 勇者だけに戻り、仲間の顔ぶれは（ほぼ確実に）昨日と違う
4. 日付を元の日に戻す: 昨日の顔ぶれが同じ並びで残っている
5. 日付と時刻の「自動設定」を元に戻す

## スーパースターの演出を見たいとき

スーパースターは約17日に1回しか出ません。確認したいときは、`Packages/RPGTodoCore/Sources/RPGTodoCore/CharacterCatalog.swift` の `drawWeight` で `.superstar: 2` を `.superstar: 1000` に一時的に変えて実行します（その日の顔ぶれは抽選済みなので、日付を翌日に進めて引き直します）。確認したら `2` に戻してください。
