# キャラクター図鑑のプロフィール（案 v1）

図鑑（要件 6.6）に表示する、キャラごとの名前・二つ名・紹介文・ひとこと・未発見時のヒント。
Phase 5 で `CharacterCatalog` のデータとして取り込む（要件 5.6 の `profile`・`hint` に、`name`・`title`・`quote` を追加）。

- 名前は既存の有名キャラと重ならないオリジナル。App Store 公開前にもう一度確認する。
- 各キャラに「タスクとの付き合い方」の性格を1つ持たせている（段取り・すき間時間・休憩・任せる…）。
- 「ひとこと」は図鑑の詳細と、加入演出の吹き出し（将来）で使う想定。
- 未発見のあいだは、シルエットと「？？？」とヒントだけを出す。
