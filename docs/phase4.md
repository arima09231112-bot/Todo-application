# Phase 4 の確認手順（カレンダー連携）

コードを書いた環境には Swift がないため、**ビルドもテストも Mac で初めて実行します**。エラーが出たら、その文字を貼ってください。

## 1. 取り込みとテスト

リポジトリの一番上のフォルダで:

```bash
git pull
xcodegen
cd Packages/RPGTodoCore && swift test
```

「CalendarSuggestion」のテスト（テンプレート・30分前・重複キー）が通ることを確認します。そのあと一番上のフォルダに戻り（`cd ../..`）、Xcode でスキーム `RPGTodo`・iPhone を選んで ▶。

> 保存データに項目（`calendarEventKey`）とテーブル（採用・除外の記録）を足しました。いままでのTodoは消えずに引き継がれるはずです。もしアプリが起動直後に落ちたら教えてください。

## 2. 実機で確認する

先に、iPhone の「カレンダー」アプリで、今日と明日に予定を作っておきます（例: 今日 15:00「定例会議」、今日 17:00「歯医者」、明日 10:00「A社 商談」）。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | カレンダータブを開く | 「カレンダーと連携する」の説明と「連携をオンにする」ボタン |
| 2 | ボタンを押す | iOS の許可ダイアログ（カレンダーへのフルアクセス）。許可する |
| 3 | 許可後 | 「今日」「明日」に予定が時刻順で並び、予定ごとに候補が出る。「定例会議の資料を確認する」「歯医者の準備をする」「A社 商談の提案資料を準備する」 |
| 4 | 「追加」を押す | ボタンが「追加済み」に変わる。ホームのタスクに、予定の**30分前の時刻**で入る（15:00の予定 → 14:30） |
| 5 | アプリを終了して開き直す | 追加した予定は「追加済み」のまま。**候補が二重に増えない**。ホームにも1件だけ |
| 6 | 別の予定の「除外」を押す | 一覧から消える |
| 7 | 右上「…」→「除外した予定を表示」 | 除外した予定が出る。「戻す」で候補に戻る |
| 8 | 予定が2件以上あるとき「すべて追加」 | 残りの候補がまとめてTodoになる |
| 9 | ホームのタスク一覧の下 | 「カレンダーからの予定」カードに次の予定が1件。タップでカレンダータブへ移る |
| 10 | 設定タブ →「カレンダーと連携する」をオフ | ホームのカードが「カレンダーと連携する」に変わり、カレンダータブは説明画面に戻る |
| 11 | iPhone の設定でカレンダーを「許可しない」にして開く | 説明と「設定アプリを開く」ボタンが出る |
| 12 | 繰り返しの予定（毎週など）がある場合 | 別の回の予定は別々に候補が出る（同じ回は二重に出ない） |

## 3. 作りのメモ

- 予定の読み取りは `RPGTodo/Features/Calendar/CalendarStore.swift`（EventKit。読み取りのみ。予定は変更しない）。
- 候補の文言と時刻は `RPGTodoCore` の `CalendarSuggestion`（端末内のテンプレート。外部には何も送らない）。
- 重複防止は「予定の識別子＋その回の開始日時」のキー（`CalendarEventKey`）。採用・除外の記録（`CalendarSuggestionRecord`）に保存する。
- 今回入れていないもの: 候補を編集してから採用（C-05）、予定の変更・削除の検知（C-08）、対象カレンダーの選択（S-01 の選択部分）。いずれも P1。
