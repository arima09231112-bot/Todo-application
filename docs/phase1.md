`RPGTodoCore` のテスト（日付・達成率・並び順・繰り返し）が通ることを確認します。

## 2. 実機で確認する

Xcode でスキーム `RPGTodo`・自分の iPhone を選んで ▶。

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 右上の「＋」→ タスク名を入力 → キーボードの「完了」 | 一覧に追加される |
| 2 | 5件作り、3件のチェック円をタップ | 「60%」「3 / 5 タスク完了」。ゲージが青く伸びる。下に「勇者 ＋ 仲間3人」 |
| 3 | 1件チェックを外す | 40%、仲間2人 |
| 4 | 時刻を付けて追加（9:00、18:00、時刻なし） | 時刻の昇順、時刻なしは末尾。完了しても行が動かない |
| 5 | 行をタップ → 名前を変更 → 保存 | 一覧に反映 |
| 6 | 行を左にスワイプ → 削除 | 消える。達成率が再計算される |
| 7 | 全部削除 | 「今日の冒険は準備中」 |
| 8 | 繰り返し「毎日」でタスクを追加 | 行に繰り返しマーク（↻）。翌日にアプリを開くと同じタスクが出る |
| 9 | 繰り返しタスクを削除 | 「この日だけ削除」「繰り返しを終了して削除」を選べる |
| 10 | 繰り返しタスクを編集して保存 | 「この日だけ変更」「今後すべて変更」を選べる |
| 11 | 「今日のタスク」右上の「…」→ 完了済みを隠す／カテゴリで絞り込み | 表示だけが変わり、達成率は変わらない |
| 12 | アプリを終了して開き直す | データが残っている |

## 3. 日付が変わるときの確認

1. 今日のタスクを数件作り、「毎日」の繰り返しタスクも1件作る
2. iPhone の「設定」→「一般」→「日付と時刻」で、自動設定をオフにして日付を翌日にする
3. アプリを開く
   - 今日のタスクが空になる（昨日の分は昨日のまま）
   - 「毎日」のタスクだけが新しく出る
   - 「…」→「未完了のタスクを見る」に、昨日の未完了タスクが出る。「今日に移す」で今日に複製される
4. 日付と時刻の「自動設定」を元に戻す
