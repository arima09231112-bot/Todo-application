# Phase 3 の確認手順（ウィジェット）

コードを書いた環境には Swift がないため、**ビルドは Mac で初めて実行します**。エラーが出たら、その文字を貼ってください。

## 1. 取り込み

リポジトリの一番上のフォルダで:

```bash
git pull
xcodegen
```

Xcode でスキーム `RPGTodo`・自分の iPhone を選んで ▶。

> ウィジェットの作り（静的な設定 → 設定項目なしのインテント設定）を変えたので、**ホーム画面の古いウィジェットは一度削除して、もう一度追加し直してください**。

## 2. 実機で確認する

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | ホーム画面を長押し →「＋」→「RPG Todo」 | 小・中・大の3つのサイズが選べる |
| 2 | 小サイズを追加 | 「今日の冒険」・達成率（大きな数字）・「3/5 完了」・パーティ（最大6体）が出る |
| 3 | 中サイズを追加 | 見出し・進捗バー・Todo最大4件・下にパーティ。背景は冒険の絵 |
| 4 | 大サイズを追加 | Todo最大8件。多いときは未完了を優先し「ほか n 件」と出る |
| 5 | 中・大のチェック（○）をタップ | **アプリを開かずに**青いチェックになり、取り消し線がつく。達成率・パーティも更新される |
| 6 | もう一度タップ | 未完了に戻る |
| 7 | チェック以外（文字や余白）をタップ | アプリのホームが開く |
| 8 | アプリでTodoを追加・完了 | ウィジェットにすぐ反映される（数秒かかることがある） |
| 9 | ウィジェットで完了 → アプリを開く | アプリ側にも完了が反映されている。達成率が同じ |
| 10 | Todo が0件の日 | 「今日の冒険は準備中」と勇者だけ |
| 11 | 設定で勇者を戦士（女）に変更 | ウィジェットの先頭も変わる |
| 12 | ダークモード | カードが暗い色になり読める。背景は暗めになる |

## 3. 0:00 の切り替え

1. タスクをいくつか作って、仲間を加える
2. iPhone の「日付と時刻」で自動設定をオフにし、日付を翌日にする
3. ウィジェットが（しばらくして）勇者だけ・新しい日のTodoに切り替わる。アプリを開くと確実に切り替わる
4. 日付を元に戻し、自動設定をオンに戻す

> ウィジェットの更新は iOS が管理するため、0:00 ちょうどには切り替わらないことがあります（数分〜の遅れは仕様として許容。要件 4.5）。

## 4. 作りのメモ

- 表示内容は `RPGTodoWidget/WidgetData.swift` が App Group の SwiftData から作る。ウィジェットが先に動いた日も、日付変更処理（記録の確定・繰り返しTodoの生成・仲間の抽選）をここで実行する（冪等）。
- チェックの処理は `RPGTodoWidget/ToggleTodoIntent.swift`（App Intents）。アプリと同じ `TodoService.toggle` を通る。
- アプリでの変更のあとは `WidgetRefresh.request()`（`reloadAllTimelines`）で更新を要求する。
- ロック画面ウィジェット（W-08）は P2 のため、今回は含めない。
