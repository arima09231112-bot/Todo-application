# RPG型Todoアプリ プロジェクトノート

日常のタスクを、RPGの冒険に変える iPhone アプリ。Todo を達成するほど勇者（ユーザー）の仲間が増える。

## リンク

- リポジトリ: https://github.com/arima09231112-bot/Todo-application
- 作業ブランチ: `claude/rpg-todo-app-requirements-7crz4u`
- 要件定義書（v0.10）: `docs/requirements.md`
- Mac のセットアップ手順: `docs/setup.md`
- 画面イメージ: `docs/images/concept-v1.png`

## 決まったこと

| 項目 | 決定 |
|---|---|
| 対応OS | iOS 26 以上（Xcode 26.5 のため。当初の iOS 27 から変更） |
| 技術 | SwiftUI / WidgetKit / SwiftData / EventKit / App Intents、Xcode プロジェクトは XcodeGen で生成 |
| 配布 | 当面は自分専用。完成度次第で App Store 公開（公開できる品質・権利で作る） |
| 1日の区切り | 0:00 |
| 未完了Todo | 自動繰り越しなし。手動で「今日に移す」 |
| 繰り返しTodo | MVP に含める（毎日・平日・曜日指定） |
| カレンダー候補 | 端末内テンプレート方式（AI は次期） |
| ダークモード | 対応（システム追従） |
| 完了チェックの色 | 青（当面。後から変えやすくしておく） |
| タブ | ホーム / カレンダー / 記録 / 設定 |
| 左上のボタン | キャラクター図鑑 |
| 加入演出 | 節目ごとに1日1回 |
| キャラの動き | **歩かない静止画**（v0.7）。そのぶんキャラ数を増やす |

## パーティのルール（v0.8）

| 達成率 | パーティ |
|---|---|
| 0〜19% | 勇者のみ |
| 20% ごと | 仲間が1人ずつ加わる（最大5人）。**誰が加わるかは日ごとのランダム（重み付き）** |
| 100% | 勇者＋仲間5人（6人） |

- 達成率 = 完了数 ÷ 当日のTodo総数 × 100（切り捨て）。0件のときは「今日の冒険は準備中」。
- ランダムの仕組み: その日の最初に、勇者用の戦士2体を除く23体から**5体を重複なし・重み付きで並び順つきで抽選**して保存。同じ日はチェックを付け外ししても顔ぶれ・順番は変わらない。新しい日に引き直し。
- 出やすさ（上から出やすい順。重みは仮）:
  1. 通常キャラ（剣士・魔法使い・弓使い・僧侶・盗賊・騎士・忍者・召喚士、各・男女の16体）重み10
  2. モンスター（スライム・ゴーレム・ドラゴン・ゴースト）重み5
  3. 魔王（男・女）重み3
  4. スーパースター 重み2（最もレア）
- 目安: 1日の編成にモンスターが入る確率は約47%、魔王は約17%、スーパースターは約6%。
- 図鑑は「発見 n / 23」のコレクション要素。
- **勇者は戦士（男）／戦士（女）から選ぶ**（設定で変更可、既定は男）。戦士2体は、勇者に選ばなかった方も含めて仲間の抽選に出ない（確定）。

## キャラ素材

- 新デザイン25体の**静止画**が完成（ほぼ正面向き）。v0.10 で**ドットに変換せず元の解像度のまま**切り出す方式に変更（256×256px。ドット化するとぼやけたため）。勇者は戦士（男）／戦士（女）の絵を使う。
- ホーム画面全体に、縦長の冒険背景（空・山・湖・森・草原）を敷く（`art/backgrounds/home_day.png`）。
- ChatGPT で生成 → `tools/sprite-pipeline/` のスクリプト（`--static --sheet --hires`）で背景だけ自動で透過（エディタは使わない）。1枚に多数のキャラをまとめて頼める。
- 素材の置き場: `art/sprites/{キャラID}.png`、Xcode 用は `Shared/Resources/Assets.xcassets`（`python3 scripts/sync_sprites.py` で同期）。旧素材は `art/archive/`。
- 制作ルールはスキル `.claude/skills/pixel-art-character/` にまとめてある。
