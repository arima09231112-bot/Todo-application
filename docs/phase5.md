# Phase 5 の確認手順（記録・図鑑）

コードを書いた環境には Swift がないため、**ビルドもテストも Mac で初めて実行します**。エラーが出たら、その文字を貼ってください。

## 1. 取り込みとテスト

リポジトリの一番上のフォルダで:

```bash
git pull
xcodegen
cd Packages/RPGTodoCore && swift test
cd ../..
```

連続達成日数・平均・図鑑の発見・「あと何件で次の仲間」・全キャラのプロフィールのテストが通ることを確認します。そのあと Xcode でスキーム `RPGTodo`・iPhone を選んで ▶。

> 「仮画面」のファイル（`ComingSoonView.swift`）を削除したので、`xcodegen` を忘れるとビルドエラーになります。

## 2. 図鑑

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | ホーム左上の本のボタン | 「キャラクター図鑑」が開く |
| 2 | ホームのパーティ（キャラが並んでいるところ）をタップ | 同じく図鑑が開く |
| 3 | 「今日の目標」 | 「あと n 件で新しい仲間が加わる」と、仲間 n / 5 のバー。5人そろうと「全員集合！」 |
| 4 | 「勇者」 | 戦士2人が常に表示され、選んでいる方に「いま」 |
| 5 | 「仲間たち」 | 23体のカード。出会ったキャラは絵と名前、まだのキャラは影絵と「？？？」とめずらしさ。今日のパーティには「今日」 |
| 6 | 右上 | 「発見 n / 23」。全員出会うと「コンプリート！」 |
| 7 | 出会ったキャラをタップ | 大きな絵・二つ名・名前・職業・ひとこと・紹介文・初めて仲間になった日・仲間になった日数 |
| 8 | まだのキャラをタップ | 影絵・「？？？」・ヒント（例:「すき間時間に、黒い影が…」） |
| 9 | チェックを外して仲間を減らす | 一度出会ったキャラは、図鑑から消えない |

## 3. 記録タブ

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 記録タブ | 上に「連続達成」「今週の平均」「今月の平均」、その下に月カレンダー |
| 2 | 月カレンダーの色 | 100% の日は緑、1〜99% は青（高いほど濃い）、タスクのない日はグレー。今日は青い枠 |
| 3 | スーパースターが仲間になった日 | 日付の右上に黄色い星 |
| 4 | 日付をタップ | その日の達成率・完了数・パーティ・タスク一覧（見るだけ） |
| 5 | 「＜」「＞」 | 前の月・次の月へ（今月より先には進めない） |
| 6 | 連続達成 | 100% の日が続いた日数。タスクのない日は途切れない。今日がまだ100%でなければ昨日まで |

過去の日の確認は、Phase 2 のときのように iPhone の日付を変えて試すか、数日使ってから見てください。
