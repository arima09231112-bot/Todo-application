# キャラクター外見定義（デザインバイブル）

全キャラ共通: 48×48px キャンバス（本体は縦 38〜44 ドット）・右向き・2〜2.5頭身・濃色 1px 輪郭・16色以内・ベタ塗り。
画面イメージ（`docs/images/concept-v1.png`）の「仲間たち」欄をたたき台にしている。

各キャラの「識別の決め手」は、ウィジェットで小さく表示しても見分けられる要素。ここを崩す変更はしない。

## 共通パレットの考え方

- 肌: 明・暗の2色を全キャラで共通にする
- 輪郭: 黒ではなく、各キャラの主色を暗くした色（例: 青系キャラは濃紺）
- 1パーツにつき「基本色＋影色」の2色、必要な部分だけハイライト1色

## hero — 勇者（ユーザー）

| 項目 | 定義 |
|---|---|
| 主色 | 赤（ハチマキ／マント）＋ 青緑（チュニック） |
| 頭 | 茶色の短髪、赤いハチマキ（後ろに結び目がたなびく） |
| 体 | 青緑のチュニック、茶色のベルト、短い赤マント |
| 武器 | 腰に小さな剣（鞘のみ見える） |
| 識別の決め手 | 赤いハチマキのなびき＋赤マント |
| 注意 | 画面イメージ案の「赤い帽子＋青い服」は有名キャラを連想させるため、帽子をハチマキに、服をチュニックに変更した（ユーザー確認済み） |

## swordsman — 剣士

| 項目 | 定義 |
|---|---|
| 主色 | 青 |
| 頭 | 青いツンツン髪（帽子なし） |
| 体 | 革の胸当て、青いズボン、茶色のブーツ |
| 武器 | 背中に大きめの剣（柄が肩の上に見える） |
| 識別の決め手 | 青い髪＋背中の剣の柄 |

## mage — 魔法使い

| 項目 | 定義 |
|---|---|
| 主色 | 紫 |
| 頭 | 紫のとんがり帽子（金色の帯）、先端が後ろに折れる |
| 体 | 紫のローブ（足元まで） |
| 武器 | 先端に宝玉の付いた木の杖 |
| 識別の決め手 | とんがり帽子のシルエット（全キャラで一番背が高い） |

## priest — 僧侶

| 項目 | 定義 |
|---|---|
| 主色 | 白＋金 |
| 頭 | 銀髪のショート |
| 体 | 白い法衣、金色の縁取り、胸元に小さな紋章（十字は避け、円と葉の形） |
| 武器 | 先が輪になった短い杖 |
| 識別の決め手 | 白い法衣（明るい面積が最も大きい） |
| 注意 | 白が背景に溶けないよう、輪郭は灰青色で必ず囲む |

## thief — 盗賊

| 項目 | 定義 |
|---|---|
| 主色 | 緑 |
| 頭 | 緑の頭巾（口元まで覆うスカーフ） |
| 体 | 緑系の軽装、茶色のポーチ |
| 武器 | 腰に短剣 |
| 識別の決め手 | 頭巾で顔の下半分が隠れている |

## knight — 騎士

| 項目 | 定義 |
|---|---|
| 主色 | 銀＋紺 |
| 頭 | 銀色の兜（面頬は上げて目が見える）、紺の羽飾り |
| 体 | 銀の全身鎧、紺のサーコート |
| 武器 | 体の前に大きな盾（紺地に金の模様） |
| 識別の決め手 | 大きな盾で体の前面が四角いシルエット |

## superstar — スーパースター（レア）

100% の日にまれに出現するレアキャラ。

| 項目 | 定義 |
|---|---|
| 主色 | ピンク＋白＋ミント（髪は黒） |
| 頭 | 黒髪のロングツインテール、ぱっつん前髪、両側にピンクとミントの大きなリボン |
| 体 | ピンクと白のアイドル風ドレス（パフスリーブ、胸元に黄色のリボン）、白い手袋 |
| 足 | ミントとピンクの厚底ブーツ、白いソックス |
| 武器 | なし（アイドル） |
| 識別の決め手 | 黒髪ツインテールの大きなシルエット＋パステルのドレス |
| 素材 | v1 確定: `art/source/superstar_walk_v1.png` → `art/sprites/superstar/`（歩行4ポーズを GPT で生成） |
| 注意 | 特別感は配色とシルエットで出す。発光・グラデーションは使わない。キラキラの残像や星が降る演出は別のエフェクト素材。ドレスのピンクが淡く白に寄りやすいので、再生成時は「はっきりしたピンク」と指定する |

| 項目 | 定義 |

## 色の重なりチェック

隊列で隣り合うキャラの主色が近すぎないこと: 赤（勇者）→ 青（剣士）→ 紫（魔法使い）→ 白（僧侶）→ 緑（盗賊）→ 銀紺（騎士）→ ピンク＋黒髪（スーパースター）。新キャラを追加するときは、この並びで主色が重ならないようにする。
