# キャラクター外見定義（デザインバイブル）

全キャラ共通: 立ち姿の静止画1枚（`art/sprites/{id}.png`）・**80×80px キャンバス**（本体は縦 60〜70 ドット。ゴーレム・ドラゴンなどは横に広い）・ほぼ正面向き・2〜2.5頭身・濃色 1色の輪郭・16色以内・ベタ塗り。

素材は新デザインの一覧シート（`art/source/cast_sheet_v2.png`）から作成した。全キャラ**同じドット密度**（1ドット≒3.2px で描かれた元画像）で取り込んでいる。新キャラを足すときは、このシートの絵柄・ドットの細かさに合わせる。

出やすさは種別ごとの重みで決まる（要件定義書 4.3.1a）: 通常キャラ（重み10）> モンスター（5）> 魔王（3）> スーパースター（2）。

## 追加するときのルール

- 種別（`job` / `monster` / `demonLord` / `superstar`）を決める。種別で出やすさが決まる。
- 外見はこの表に追記してから作る。ID は `{職業}_{m|f}` またはモンスター名の小文字英語。
- 同じ種別の中で、主なシルエット（帽子・武器・体型）が既存キャラと被らないようにする。
- 抽選で隣り合うキャラが毎日変わるので、**どのキャラ同士が隣り合っても見分けられる**ようにする（色だけでなくシルエットで区別）。
