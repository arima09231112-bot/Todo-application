# キャラクター外見定義（デザインバイブル）

全キャラ共通: 32×32px・右向き・2〜2.5頭身・濃色 1px 輪郭・16色以内・ベタ塗り。
画面イメージ（`docs/images/concept-v1.png`）の「仲間たち」欄をたたき台にしている。

各キャラの「識別の決め手」は、ウィジェットで小さく表示しても見分けられる要素。ここを崩す変更はしない。

## 共通パレットの考え方

- 肌: 明・暗の2色を全キャラで共通にする
- 輪郭: 黒ではなく、各キャラの主色を暗くした色（例: 青系キャラは濃紺）
- 1パーツにつき「基本色＋影色」の2色、必要な部分だけハイライト1色

## hero — 勇者（ユーザー）

| 項目 | 定義 |
|---|---|
| 主色 | 赤（ハチマキ／マント）＋ 青緑（チュニック） |
| 頭 | 茶色の短髪、赤いハチマキ（後ろに結び目がたなびく） |
| 体 | 青緑のチュニック、茶色のベルト、短い赤マント |
| 武器 | 腰に小さな剣（鞘のみ見える） |
| 識別の決め手 | 赤いハチマキのなびき＋赤マント |
| 注意 | 画面イメージ案の「赤い帽子＋青い服」は有名キャラを連想させるため、帽子をハチマキに、服をチュニックに変更する（提案。ユーザー確認待ち） |

## swordsman — 剣士

| 項目 | 定義 |
|---|---|
| 主色 | 青 |
| 頭 | 青いツンツン髪（帽子なし） |
| 体 | 革の胸当て、青いズボン、茶色のブーツ |
| 武器 | 背中に大きめの剣（柄が肩の上に見える） |
| 識別の決め手 | 青い髪＋背中の剣の柄 |

## mage — 魔法使い

| 項目 | 定義 |
|---|---|
| 主色 | 紫 |
| 頭 | 紫のとんがり帽子（金色の帯）、先端が後ろに折れる |
| 体 | 紫のローブ（足元まで） |
| 武器 | 先端に宝玉の付いた木の杖 |
| 識別の決め手 | とんがり帽子のシルエット（全キャラで一番背が高い） |

## priest — 僧侶

| 項目 | 定義 |
|---|---|
| 主色 | 白＋金 |
| 頭 | 銀髪のショート |
| 体 | 白い法衣、金色の縁取り、胸元に小さな紋章（十字は避け、円と葉の形） |
| 武器 | 先が輪になった短い杖 |
| 識別の決め手 | 白い法衣（明るい面積が最も大きい） |
| 注意 | 白が背景に溶けないよう、輪郭は灰青色で必ず囲む |

## thief — 盗賊

| 項目 | 定義 |
|---|---|
| 主色 | 緑 |
| 頭 | 緑の頭巾（口元まで覆うスカーフ） |
| 体 | 緑系の軽装、茶色のポーチ |
| 武器 | 腰に短剣 |
| 識別の決め手 | 頭巾で顔の下半分が隠れている |

## knight — 騎士

| 項目 | 定義 |
|---|---|
| 主色 | 銀＋紺 |
| 頭 | 銀色の兜（面頬は上げて目が見える）、紺の羽飾り |
| 体 | 銀の全身鎧、紺のサーコート |
| 武器 | 体の前に大きな盾（紺地に金の模様） |
| 識別の決め手 | 大きな盾で体の前面が四角いシルエット |

## superstar — スーパースター（特別）

| 項目 | 定義 |
|---|---|
| 主色 | 金＋白 |
| 頭 | 金髪、星形の髪飾り（または星の冠） |
| 体 | 白と金の衣装、星柄のマント |
| 武器 | 先端が星の杖 |
| 識別の決め手 | 星の髪飾り＋金色の面積が最も大きい |
| 注意 | 特別感は配色と星の形で出す。発光・グラデーションは使わない。キラキラの残像や星が降る演出は別のエフェクト素材 |

## archer — 弓使い（次期）

| 項目 | 定義 |
|---|---|
| 主色 | 橙＋茶 |
| 頭 | 橙色のポニーテール、羽根付きの帽子 |
| 体 | 茶色の革鎧、背中に矢筒 |
| 武器 | 手に短弓 |
| 識別の決め手 | 弓の弧のシルエット＋ポニーテール |

## 色の重なりチェック

隊列で隣り合うキャラの主色が近すぎないこと: 赤（勇者）→ 青（剣士）→ 紫（魔法使い）→ 白（僧侶）→ 緑（盗賊）→ 銀紺（騎士）→ 金（スーパースター）。新キャラを追加するときは、この並びで主色が重ならないようにする。
