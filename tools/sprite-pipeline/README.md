# sprite-pipeline

ChatGPT の画像生成で作った「ドット絵風」の画像を、アプリで使えるスプライト（32×32px・16色・背景透過・歩行4フレーム）に**自動で**整形するスクリプトです。ドット絵エディタでの手作業は不要です。

## 素材づくりの流れ

1. 下のプロンプトで ChatGPT にキャラ画像を生成してもらう
2. 生成画像をチャットに貼る（またはリポジトリの `art/source/` に置く）
3. スクリプトを実行し、`preview_sheet.png` と `preview_walk.gif` を見て確認
4. 気に入らないキャラだけ生成し直す（1〜3 を繰り返す）

スクリプトの実行は Claude Code 側で行えるため、ユーザーの作業は「生成して貼る」「プレビューを見て OK か判断する」だけです。

## 実行方法

```bash
python3 tools/sprite-pipeline/build_sprites.py art/source/party.png \
  --names hero,swordsman,mage,priest,thief,knight,superstar \
  --out art/sprites
```

- 1枚の画像に複数キャラが横に並んでいれば、左から順に `--names` の名前で切り出します。
- 出力: `{名前}_right_{0..3}.png`（歩行4フレーム）、`preview_sheet.png`、`preview_walk.gif`
- 縁に背景色のにじみが残る場合は `--tolerance` を上げ、キャラの一部が消える場合は下げます。

## ChatGPT 用プロンプト

### 1. キャラ一覧（最初に絵柄を決める）

```
オリジナルのレトロRPG風ドット絵キャラクターを7体、横一列に等間隔で並べてください。
- 左から順に：
  1. 勇者：茶色の短髪に赤いハチマキ、青緑のチュニック、短い赤マント、腰に剣
  2. 剣士：青いツンツン髪、革の胸当て、背中に大きな剣
  3. 魔法使い：紫のとんがり帽子（金の帯）、紫のローブ、宝玉の杖
  4. 僧侶：銀髪、金の縁取りの白い法衣、先が輪になった杖
  5. 盗賊：口元まで覆う緑の頭巾、緑の軽装、腰に短剣
  6. 騎士：銀の兜と鎧、紺のサーコート、大きな紺の盾
  7. スーパースター：金髪に星の髪飾り、白と金の衣装、星柄のマント、星の杖
- 全員「右向きの横顔」で立っている全身像。2頭身のデフォルメ
- 32×32ピクセル程度の解像度に見える、粗いドットのピクセルアート
- アンチエイリアスなし、グラデーションなし、ベタ塗り、濃い色の輪郭線
- キャラ同士は重ならないように十分な間隔をあける
- 背景は無地のマゼンタ（#FF00FF）一色。影や地面は描かない
- 既存のゲームやアニメのキャラクターに似せない完全オリジナルデザイン
- 光るエフェクトやグラデーションは使わない
```

### 2. 1体だけ作り直す

```
添付画像と同じ絵柄・同じサイズ感で、「{職業}」だけを1体描いてください。
右向きの横顔の全身像、背景は無地のマゼンタ（#FF00FF）一色。
アンチエイリアスなし、ベタ塗り、濃い色の輪郭線。
```

## 注意

- キャラの外見定義は `.claude/skills/pixel-art-character/references/characters.md` が正です。プロンプトを変えるときはそちらと合わせてください。

- 背景を無地（マゼンタ推奨）にすると、背景除去が安定します。
- 歩行フレームは「上半身の上下の揺れ＋片足の踏み出し」を自動生成します。凝った動きはできませんが、小さく表示する前提では十分に歩いて見えます。
- 生成に使ったプロンプトと元画像は `docs/assets-log/` に保存し、素材の出どころを記録してください（App Store 公開時の権利確認のため）。
