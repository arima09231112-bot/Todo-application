# 紹介動画の作成（SNS 用・縦 1080×1920・約44秒）

アプリの素材（キャラ・背景・アイコン）だけで、紹介動画を作る。画面は実機の録画ではなく、アプリの見た目を再現したもの。

```bash
python3 tools/promo-video/make_promo.py 出力先.mp4              # 動画を作る（約1分半）
python3 tools/promo-video/make_promo.py out --preview 6 15.8   # 指定した秒の静止画だけ確認する
```

必要なもの: Python 3、Pillow、numpy、ffmpeg。日本語フォントは `make_promo.py` 冒頭の `FONT_UI`（本文）と `FONT_PIXEL`（見出し）で指定する。

## 構成

| 秒 | 内容 |
|---|---|
| 0〜5 | 夜空に「Todoをクエストに変える。」→ 朝へ |
| 5〜19 | クエストを完了するたびに仲間が増える → 100% で「全員集合！」と星 |
| 19〜27 | 仲間は毎日ちがう（4日分の顔ぶれ。最後はスーパースター） |
| 27〜31.5 | ウィジェットからワンタップで完了（小・中・大） |
| 31.5〜36 | 図鑑をうめよう（影絵から発見へ。名前はジョブ名だけ） |
| 36〜44 | アイコンと「Daily Quest」・キャッチコピー |

台本の時刻・文言・キャラは `make_promo.py` の「台本」の節で変える。BGM は同じファイルで numpy から作る（既定は電子音のダンス風: シンセ・パッド・アルペジオ・ベース・4つ打ち。`--music orchestra` でオーケストラ風）。効果音のピープ音は入れない。
